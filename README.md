## Built with

React, TypeScript, Vite, Tailwind CSS, and Lucide icons.

## Run locally

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm exec vite --host 127.0.0.1 --port 3000
```

Then open [http://localhost:3000](http://localhost:3000).

## Deploy

The project is configured for static deployment on Vercel. Import the GitHub repository into Vercel; the build and output settings are in `vercel.json`.
